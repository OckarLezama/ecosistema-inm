# Pruebas automáticas

Revisan que el tablero funcione antes de publicar un cambio: las 40 consultas de Pregunta a INAMI contra sumas independientes, el diseño en escritorio y celular, las descargas, la pantalla completa en 28 tamaños de pantalla (incluidas pantallas táctiles con escala de Windows), los círculos del mapa, el clic en países, la ficha, el contexto y la pantalla completa de Control.

Instalar una vez: `npm install` y `npx playwright install chromium`.
Correr todas: `npm run todas`. Las capturas quedan en `capturas/` (no se suben).
